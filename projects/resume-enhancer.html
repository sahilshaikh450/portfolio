Resume Enhancer

AI-powered career platform for job seekers

Live Demo Code

About the project

Resume Enhancer is an AI career platform that helps job seekers stand out. Build a resume in a drag-and-drop editor with live ATS readiness scoring, analyze an existing PDF resume, generate tailored cover letters and interview questions, and chat with an AI career coach — all powered by Groq-hosted LLMs.

Tech Stack

Next.js 14 React Tailwind CSS Node.js Express.js MongoDB Groq API JWT

Key Features

  • Resume Builder with templates, drag-and-drop sections and PDF export
  • ATS Analyzer with section-by-section score breakdown
  • AI resume enhancement and keyword alignment
  • Cover letter and interview Q&A generators
  • AI Career Coach chat with memory and optional RAG
  • Email / Google sign-in with JWT and score history
