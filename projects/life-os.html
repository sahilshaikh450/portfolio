LIFE OS

Futuristic full stack productivity platform

Live Demo

About the project

LIFE OS is a full stack productivity and personal management platform built to help users organize their daily life. It combines habit tracking with streaks, a task engine with priorities and Pomodoro, and Wealth Map expense analytics behind secure JWT authentication, in one modern ecosystem with a premium UI.

Tech Stack

React JavaScript Zustand Framer Motion Recharts Axios Java Spring Boot Spring Security JWT JPA H2

Key Features

  • Secure JWT authentication with refresh tokens
  • Habit Forge: streaks, weekly report card and completion stats
  • Task Engine: priorities, statuses, due dates and Pomodoro
  • Wealth Map: income / expense tracking with charts
  • Category breakdown, savings rate and 6-month trend
  • Protected routes, REST API and responsive dark / light UI
