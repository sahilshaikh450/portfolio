LIFE OS

LIFE OS is a futuristic full stack productivity and personal management platform built to help users organize their daily life efficiently. It combines habit tracking, task management, expense analytics, secure authentication and productivity systems into one modern ecosystem with a premium user experience.

Features

  • Secure JWT authentication system
  • Habit tracking and streak management
  • Task and productivity management
  • Expense tracking and budgeting (Wealth Map)
  • Interactive analytics dashboard
  • Protected routes and authorization
  • REST API architecture
  • Responsive modern UI design

Tech Stack

React JavaScript Zustand Axios Java Spring Boot Spring Security JWT JPA H2 Database
