## About

A fast, responsive portfolio that showcases my skills, projects, timeline and
achievements. Everything is written by hand — no build step, no framework,
just open `index.html`.

## Features

- Animated signature intro and typing hero
- Scroll-reveal animations and mouse-follow card spotlight
- Light / dark theme with saved preference
- Dedicated project pages with features and tech stack
- Animated timeline with scroll progress
- Fully responsive for mobile, tablet and desktop

## Run locally

```bash

cd portfolio
python3 -m http.server 8000   # then open http://localhost:8000
```
